# 내전 ELO 레이팅 설명서

현재 구현(S4 후속 변경 2 반영, 2026-10-31) 기준입니다. 수치는 `packages/core/src`·`packages/shared/src`의 코드와 `.env.example`에서 직접 확인했습니다.

핵심 원칙: **티어와 라인은 팀을 나눌 때만 쓰고, 내전 ELO는 티어와 상관없이 내전 결과만으로 오르내리는 「이 디스코드 안의 내전 실력」 점수입니다.**

## 1. 한눈에 보기

| 질문 | 답 |
| --- | --- |
| ELO가 무엇인가요? | 내전 결과로만 바뀌는 서버 자체 실력 점수입니다. 라이엇 티어와는 별개이고, 이 점수로 멤버끼리 순위를 매깁니다. |
| 언제 바뀌나요? | 운영진이 **결과를 승인한 순간**에만 바뀝니다. 입력·제출 단계에서는 바뀌지 않습니다. |
| 누구의 점수가 바뀌나요? | 팀에 배정된 참가(`joined`) 멤버입니다. 노쇼 표시자와 팀에 배정되지 않은 사람은 제외됩니다. |
| 게임별로 따로 있나요? | 네. 게임(롤 협곡, 롤체, 스팀 게임)마다, 시즌마다 점수가 따로 있습니다. |
| 시작 점수는? | 티어와 상관없이 **전원 1000점**입니다. 새 시즌마다 모두 다시 1000점에서 시작합니다(3절). |
| 한 판에 얼마나 변하나요? | 이기면 보통 +10~25점, 지면 그 절반인 −5~12점입니다(4절). |
| 랭킹에는 언제 나오나요? | 그 시즌에 5경기 이상 치른 뒤부터입니다(7절). |

## 2. 점수가 하는 일 세 가지

1. **ELO 랭킹:** 시즌별 순위를 정합니다.
2. **팀 자동 밸런스:** 팀을 나눌 때 실력값에 조금(최대 20%) 섞입니다. 밸런스의 중심은 티어입니다(6절).
3. **프로필 그래프:** 변동 내역(`rating_history`)을 레이팅 그래프로 보여 줍니다.

## 3. 시작 점수 정하기

### 3-1. 처음 점수가 정해지는 시점

멤버가 **그 시즌에 처음 결과가 반영될 때** 그 시즌의 점수 행이 만들어집니다. 가입이나 내전 참가 시점이 아닙니다. 이후에는 경기 결과로만 바뀝니다.

### 3-2. 시작 점수 = 전원 1000

```
새 점수 행의 시작 점수 = 1000   (티어, 지난 시즌 점수와 무관)
```

- 상수 `RATING_START_ELO`(`packages/shared/src/scrims.ts`)입니다. 환경 변수로 바꾸지 않습니다.
- 다이아든 실버든 언랭이든, 라이엇 연동을 안 했든 모두 1000에서 시작합니다.
- 시즌 중간에 합류한 멤버도 1000에서 시작합니다. 이 서버 내전 기록이 아직 없다는 뜻입니다.

### 3-3. 새 시즌 = 완전 초기화

- 새 시즌의 점수 행도 **1000**으로 만들어집니다. 지난 시즌 점수는 이어지지 않습니다(예전의 소프트 리셋은 없앴습니다).
- 지난 시즌 기록은 시즌 최종 순위(`season_standings`), 뱃지, 점수 변동 내역(`rating_history`)으로 남습니다.
- K 값의 「신규 멤버」 판정(4-2)은 시즌과 무관하게 전체 경기 수로 셉니다. 새 시즌에 1000으로 돌아가도 신규 K(40)로 돌아가지는 않습니다.

### 3-4. 티어는 어디에 쓰나요? (티어 환산값)

티어는 ELO에는 들어가지 않고, **팀 자동 밸런스의 실력값**(6절)에만 쓰입니다. 화면에서는 「티어 환산값」이라고 부릅니다. 티어 랭킹의 「티어 점수」(7-2)와는 다른 값입니다.

연동한 **대표 계정의 최신 솔로 랭크 티어**(롤체는 롤체 랭크)를 기준으로 합니다. 디비전과 LP는 보지 않습니다.

| 티어 | 티어 환산값 |
| --- | --- |
| 아이언 | 600 |
| 브론즈 | 800 |
| 실버 | 1000 |
| 골드 | 1200 |
| 플래티넘 | 1400 |
| 에메랄드 | 1600 |
| 다이아몬드 | 1800 |
| 마스터 · 그랜드마스터 · 챌린저 | 2000 |
| 언랭 · 티어 없음 · 연동 없음 | 1000 |
| 스팀 게임 | 1000 (티어가 없으므로 항상) |

개발 문서 7-1의 「티어당 200점 간격, 티어 연동이 없으면 1000」 표를 그대로 쓰되, 용도를 ELO 시작값에서 밸런스 재료로 바꿨습니다.

## 4. 한 판의 점수 계산

### 4-1. 팀 게임(롤 협곡 등)

1. 각 팀의 레이팅 = 팀원 **현재 점수의 평균**입니다.
2. 이길 확률(기대 승률)을 구합니다.

```
E(A팀) = 1 / ( 1 + 10^((B팀 평균 − A팀 평균) / 400) )
```

3. 참가자 각자의 변동을 구합니다.

```
승리: 반올림( K × (1 − E) )
패배: 반올림( K × (0 − E) × 패배 배율 )
```

패배 배율 기본값은 0.5입니다(`SCRIM_ELO_LOSS_RATIO`, 0 이상 1 이하). 지는 쪽은 같은 조건에서 이기는 경우의 절반만 잃습니다. 배율 1이면 일반 ELO처럼 대칭이고, 0이면 져도 점수가 내려가지 않습니다.

기대 승률 참고표(팀 평균 차이):

| 평균 차이 | 높은 팀 기대 승률 |
| --- | --- |
| 0 | 50% |
| 100 | 약 64% |
| 200 | 약 76% |
| 400 | 약 91% |

### 4-2. K 값

| 조건 | K | 환경 변수 |
| --- | --- | --- |
| 그 게임의 승인된 rated 내전이 **10경기 미만**(이번 경기 반영 전) | 40 | `SCRIM_ELO_K_NEW`, `SCRIM_ELO_NEW_PLAYER_GAMES` |
| 그 외 | 32 | `SCRIM_ELO_K_BASE` |

- 경기 수는 시즌과 무관하게 **그 게임 전체 기간**의 승인 경기 수로 셉니다.
- K는 참가자마다 따로 적용합니다. 같은 팀 안에서도 신규 멤버는 변동이 더 큽니다.
- 패배 배율 때문에 한 판의 점수 합은 0이 아니라 대체로 양수입니다(4-5).

### 4-3. 계산 예시

**예시 A: 비슷한 팀** (블루 평균 1340, 레드 평균 1336, 모두 K 32, 패배 배율 0.5)

- 블루 기대 승률 약 50.6%
- 블루 승리: 블루 각자 +16, 레드 각자 −8

**예시 B: 점수 차가 큰 팀** (블루 평균 1500, 레드 평균 1300, 모두 K 32, 패배 배율 0.5)

- 블루 기대 승률 약 76%

| 결과 | 블루 | 레드 |
| --- | --- | --- |
| 블루 승리(예상대로) | +8 | −4 |
| 레드 승리(이변) | −12 | +24 |

같은 판에서 K 40인 신규 멤버가 레드에 있다면 이변 때 +30, 블루가 이기면 −5입니다.

### 4-4. 개인 순위 게임(롤체 등 팀이 없는 게임)

- 참가자 모든 쌍을 1:1 대결로 봅니다. 순위가 높은 쪽이 승리입니다.
- 모든 상대와의 `(결과 − 기대 승률)`을 더하고 `K ÷ (인원 − 1)`을 곱합니다. 이 값이 음수이면 패배 배율을 곱하고, 그다음 반올림합니다.
- 승패 기록은 **상위 절반**(2 × 순위 ≤ 인원)이 승리, 나머지가 패배입니다. 배율은 승패 기록이 아니라 점수 변동의 부호로 정합니다. 승리로 기록돼도 변동이 음수면 배율을 받습니다.
- 동순위는 없습니다. 순위는 1부터 빠짐없이 매깁니다.

### 4-5. 패배 배율의 효과

- **점수가 전체적으로 오릅니다.** 비슷한 5:5 경기(K 32)에서 이긴 팀 +16, 진 팀 −8이면 한 판에 전체 점수가 40점 늘어납니다.
- **참여량도 점수에 들어갑니다.** 승률 50%인 멤버도 경기당 평균 약 +4점이 쌓입니다. 랭킹은 실력과 함께 경기 수도 반영합니다.
- **늦게 온 멤버는 상대적으로 낮게 시작합니다.** 시작 점수는 1000으로 고정이지만 기존 멤버 점수는 시즌 중에 오릅니다.
- 상승은 그 시즌 안에서만 쌓입니다. 새 시즌마다 1000으로 초기화하므로 시즌 시작 평균은 항상 1000입니다(시즌 30경기, 승률 50%면 시즌 끝 약 +120점).
- 이미 승인된 경기는 다시 계산하지 않습니다. 배율 변경은 이후 승인부터 적용됩니다.

### 4-6. 반영되지 않는 경우

| 경우 | 점수 |
| --- | --- |
| `rated=false`로 만든 내전 | 결과 입력·승인은 같지만 점수는 그대로 |
| 노쇼로 표시된 참가자 | 대상에서 제외 |
| 팀에 배정되지 않은 참가자 | 대상에서 제외 |
| 한 팀이 0명이거나, 개인 순위 게임에서 대상이 2명 미만 | 점수 반영 없음 |
| 결과가 반려됨 | 제출자가 다시 입력(점수는 그대로) |
| 승인 **뒤**의 노쇼 표시·정정 | 이미 반영된 점수는 바뀌지 않음 |

점수에는 하한과 상한이 없습니다. 승인된 결과는 현재 수정하거나 취소할 수 없습니다.

## 5. 시즌과 점수

- 시즌은 보통 **3개월**(KST 달력 월 기준)이고, 시즌이 하나도 없을 때 첫 결과 승인 시 자동으로 만듭니다(`SEASON_AUTO_LENGTH_MONTHS`).
- 시즌이 끝나면(종료 시각 + 60초 이후) 종료 작업이 돕니다.
  - 그 시즌 **5경기 이상**인 멤버의 최종 순위를 저장합니다.
  - 게임별 1~3위에게 뱃지를 줍니다.
- 종료 작업은 점수를 바꾸지 않습니다. 새 시즌의 첫 결과가 승인될 때 각자의 새 점수 행이 1000으로 만들어집니다.
- 그래서 시즌 초반에는 모두 1000이고 5경기를 채운 사람이 없어 ELO 랭킹이 비어 있다가, 경기가 쌓이며 채워집니다. 지난 시즌 상위권도 같은 자리에서 다시 시작합니다.
- 시즌이 끝난 뒤 다음 승인이 나기 전까지는 「현재 시즌 없음」 상태입니다(Q2).
- 시즌 마지막 날 경기가 종료 후에 승인되면 새 시즌에 반영됩니다(Q3).

## 6. 팀 자동 밸런스와의 관계

ELO는 **결과 기록·순위용 점수**이고, 팀을 나눌 때는 티어 중심의 **실력값**과 **라인**을 씁니다.

### 6-1. 실력값

```
실력값 = 반올림( w × 내전 ELO + (1 − w) × 티어 환산값 )
w = 0.2 × min( 이번 시즌 그 게임 경기 수 / 10 , 1 )
```

| 이번 시즌 경기 수 | w (내전 ELO 비중) | 티어 비중 |
| --- | --- | --- |
| 0 | 0% | 100% |
| 1 | 2% | 98% |
| 5 | 10% | 90% |
| 10 이상 | 20% | 80% |

- 0.2(`BALANCE_ELO_WEIGHT_MAX`)와 10(`BALANCE_FULL_WEIGHT_GAMES`)은 코드 상수입니다.
- 경기 수는 **이번 시즌** 경기 수입니다. 지난 시즌에 많이 뛰었어도 새 시즌 0경기면 w = 0입니다. 새 시즌 ELO는 모두 1000이라 정보가 없는 값을 섞지 않기 위해서입니다.
- 이번 시즌 점수 행이 없으면 내전 ELO 자리에 1000을 넣습니다(경기 수가 0이라 실력값에는 영향 없음).
- 예: 다이아(티어 환산값 1800), 이번 시즌 5경기, 내전 ELO 1000 → 0.1 × 1000 + 0.9 × 1800 = **1720**. 10경기 이상이면 **1640**.
- ELO가 움직이는 폭: 같은 티어 두 멤버가 ELO 1300과 900이면 w 20%에서 실력값 차이는 80점입니다. 티어 한 단계(200점)의 40%라, 티어가 밸런스를 주도하고 ELO는 미세 조정입니다.

### 6-2. 라인(1지망·2지망)

- 롤 내전의 참가 신청·작성 화면은 1지망·2지망을 **라이엇 대표 계정의 솔로 랭크 최근 20경기 주 라인·보조 라인**으로 미리 골라 둡니다. 프로필의 「주 포지션」과 같은 값입니다(`GET /me/position-suggestions`).
- 「솔로 랭크 최근 N경기 기준으로 골라 뒀어요. 바꿔도 돼요.」 안내가 나오고, 본인이 바꾸면 바꾼 값이 저장됩니다. 서버는 받은 값을 그대로 저장하고 빈 값을 몰래 채우지 않습니다.
- 라이엇 연동이 없거나 최근 솔로 랭크 기록이 없으면 지금처럼 빈 선택이고 본인이 고릅니다.
- 이미 저장된 전적만 씁니다. 전적 동기화가 오래 멈췄으면 예전 라인이 추천될 수 있습니다(Q13, 본인이 바꿀 수 있음).

### 6-3. 팀 나누기

- 정원 2~16명 범위의 모든 조합을 따져 총 비용이 낮은 상위 3안을 보여 줍니다.
- 총 비용 = 전력 차 + 50 × 포지션 비용(1지망 0, 2지망 1, 그 외 3). 전력 차 = 두 팀 실력값 평균의 차이 × 전체 인원 ÷ 2.

## 7. 랭킹에 나오는 방식

### 7-1. 내전 ELO 랭킹

- 게임별·시즌별 목록입니다. **그 시즌에 5경기 이상**(승 + 패) 치른 멤버만 나옵니다(`RANKING_ELO_MIN_GAMES`).
- 정렬 순서: 점수 높은 순 → 승률 높은 순 → 경기 수 많은 순 → 사용자 id.
- 5분 단위로 캐시합니다. 순위 변동(▲▼)은 이번 주 월요일(KST) 0시 기준 순위와 비교합니다.
- 끝난 시즌은 종료 때 저장한 최종 순위를 보여 줍니다.

### 7-2. 티어 랭킹(ELO와 별개)

```
티어 점수 = 티어 순서 × 400 + 디비전 점수 × 100 + LP
```

예: 다이아몬드 II 45LP = 6 × 400 + 2 × 100 + 45 = 2645. 마스터 이상은 디비전 없이 `티어 × 400 + LP`이고, 언랭은 제외됩니다. 이 점수는 내전 ELO와 섞이지 않습니다.

## 8. 설정값과 코드 위치

| 값 | 기본 | 바꾸는 곳 |
| --- | --- | --- |
| K 기본 / 신규 / 신규 기준 경기 수 | 32 / 40 / 10 | 환경 변수 `SCRIM_ELO_K_BASE`, `SCRIM_ELO_K_NEW`, `SCRIM_ELO_NEW_PLAYER_GAMES` |
| 패배 배율 | 0.5 | `SCRIM_ELO_LOSS_RATIO` |
| 랭킹 노출 최소 경기 | 5 | `RANKING_ELO_MIN_GAMES` |
| 시즌 자동 길이 | 3개월 | `SEASON_AUTO_LENGTH_MONTHS` |
| 시작 점수 1000 | 1000 | 코드 상수 `RATING_START_ELO`(`packages/shared/src/scrims.ts`) |

## 9. 결정 기록

### 9-1. 시작 점수를 전원 1000으로 통일 — 결정됨(2026-10-31)

사용자 결정으로 **전원 1000 시작, 새 시즌마다 1000으로 완전 초기화**로 바꿨습니다(계약 20절, D182–D195). 티어는 ELO에서 빼고 팀 밸런스 실력값에만 씁니다. 이 결정으로 Q1(신규 고티어가 기존 멤버보다 높게 시작)과 Q5(5경기 미만도 소프트 리셋)는 해당이 없어졌습니다.

- 이미 승인된 경기와 현재 시즌에 이미 있는 점수 행은 다시 계산하지 않았습니다. 실제 운영 데이터가 아직 없어 영향이 없다고 판단했습니다(Q11). 운영 데이터가 있었다면 이번 시즌은 티어로 시작한 기존 행과 1000으로 시작한 새 행이 섞였을 것입니다.
