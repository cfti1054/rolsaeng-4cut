# 내전 ELO 레이팅 설명서

현재 구현(S4 후속 변경 반영, 2026-10-31) 기준입니다. 수치는 `packages/core/src`의 코드와 `.env.example`에서 직접 확인했습니다.

## 1. 한눈에 보기

| 질문 | 답 |
| --- | --- |
| ELO가 무엇인가요? | 내전 결과로만 바뀌는 서버 자체 실력 점수입니다. 라이엇 티어와는 별개입니다. |
| 언제 바뀌나요? | 운영진이 **결과를 승인한 순간**에만 바뀝니다. 입력·제출 단계에서는 바뀌지 않습니다. |
| 누구의 점수가 바뀌나요? | 팀에 배정된 참가(`joined`) 멤버입니다. 노쇼 표시자와 팀에 배정되지 않은 사람은 제외됩니다. |
| 게임별로 따로 있나요? | 네. 게임(롤 협곡, 롤체, 스팀 게임)마다, 시즌마다 점수가 따로 있습니다. |
| 시작 점수는? | 이전 시즌 기록이 있으면 소프트 리셋 값, 없으면 티어 시드입니다(3절). |
| 한 판에 얼마나 변하나요? | 이기면 보통 +10~25점, 지면 그 절반인 −5~12점입니다(4절). |
| 랭킹에는 언제 나오나요? | 그 시즌에 5경기 이상 치른 뒤부터입니다(7절). |

## 2. 점수가 하는 일 세 가지

1. **ELO 랭킹:** 시즌별 순위를 정합니다.
2. **팀 자동 밸런스:** 팀을 나눌 때 실력값의 한 재료로 쓰입니다(6절).
3. **프로필 그래프:** 변동 내역(`rating_history`)을 레이팅 그래프로 보여 줍니다.

## 3. 시작 점수 정하기

### 3-1. 처음 점수가 정해지는 시점

멤버가 **그 시즌에 처음 결과가 반영될 때** 그 시즌의 점수 행이 만들어집니다. 가입이나 내전 참가 시점이 아닙니다. 시작 점수는 이 한 번만 계산하고, 이후에는 경기 결과로만 바뀝니다.

### 3-2. 시작 점수 결정 순서

```
이전 시즌 점수 행이 있다  →  소프트 리셋 값
이전 시즌 점수 행이 없다  →  티어 시드
```

- 이전 시즌 점수 행은 **가장 최근 행 하나**만 봅니다. 시즌을 건너뛰어도 그 행에서 한 번만 리셋합니다.
- 이전 시즌에 5경기 미만이었던 멤버도 같은 소프트 리셋을 받습니다(Q5).

### 3-3. 티어 시드

연동한 **대표 계정의 최신 솔로 랭크 티어**(롤체는 롤체 랭크)를 기준으로 합니다. 디비전과 LP는 보지 않습니다.

| 티어 | 시드 |
| --- | --- |
| 아이언 | 600 |
| 브론즈 | 800 |
| 실버 | 1000 |
| 골드 | 1200 |
| 플래티넘 | 1400 |
| 에메랄드 | 1600 |
| 다이아몬드 | 1800 |
| 마스터 · 그랜드마스터 · 챌린저 | 2000 |
| 언랭 · 티어 없음 · 연동 없음 | 1000 |
| 스팀 게임 | 1000 (티어가 없으므로 항상) |

개발 문서 7-1의 「티어당 200점 간격, 티어 연동이 없으면 1000」을 그대로 따른 값입니다.

### 3-4. 소프트 리셋 값

```
새 시즌 시작 점수 = 1000 + 반올림( (지난 시즌 마지막 점수 − 1000) × 0.5 )
```

비율 0.5는 환경 변수 `SEASON_SOFT_RESET_RATIO`로 바꿀 수 있습니다. 1000을 기준으로 차이를 절반으로 줄입니다.

| 지난 시즌 점수 | 새 시즌 시작 점수 |
| --- | --- |
| 1800 | 1400 |
| 1600 | 1300 |
| 1421 | 1211 |
| 1000 | 1000 |
| 800 | 900 |

- 반올림은 0에서 먼 쪽으로 합니다(999는 −0.5가 −1이 되어 999).
- 1000을 기준으로 위아래가 대칭입니다.

## 4. 한 판의 점수 계산

### 4-1. 팀 게임(롤 협곡 등)

1. 각 팀의 레이팅 = 팀원 **현재 점수의 평균**입니다.
2. 이길 확률(기대 승률)을 구합니다.

```
E(A팀) = 1 / ( 1 + 10^((B팀 평균 − A팀 평균) / 400) )
```

3. 참가자 각자의 변동을 구합니다.

```
승리: 반올림( K × (1 − E) )
패배: 반올림( K × (0 − E) × 패배 배율 )
```

패배 배율 기본값은 0.5입니다(`SCRIM_ELO_LOSS_RATIO`, 0 이상 1 이하). 지는 쪽은 같은 조건에서 이기는 경우의 절반만 잃습니다. 배율 1이면 일반 ELO처럼 대칭이고, 0이면 져도 점수가 내려가지 않습니다.

기대 승률 참고표(팀 평균 차이):

| 평균 차이 | 높은 팀 기대 승률 |
| --- | --- |
| 0 | 50% |
| 100 | 약 64% |
| 200 | 약 76% |
| 400 | 약 91% |

### 4-2. K 값

| 조건 | K | 환경 변수 |
| --- | --- | --- |
| 그 게임의 승인된 rated 내전이 **10경기 미만**(이번 경기 반영 전) | 40 | `SCRIM_ELO_K_NEW`, `SCRIM_ELO_NEW_PLAYER_GAMES` |
| 그 외 | 32 | `SCRIM_ELO_K_BASE` |

- 경기 수는 시즌과 무관하게 **그 게임 전체 기간**의 승인 경기 수로 셉니다.
- K는 참가자마다 따로 적용합니다. 같은 팀 안에서도 신규 멤버는 변동이 더 큽니다.
- 패배 배율 때문에 한 판의 점수 합은 0이 아니라 대체로 양수입니다(4-5).

### 4-3. 계산 예시

**예시 A: 비슷한 팀** (블루 평균 1340, 레드 평균 1336, 모두 K 32, 패배 배율 0.5)

- 블루 기대 승률 약 50.6%
- 블루 승리: 블루 각자 +16, 레드 각자 −8

**예시 B: 점수 차가 큰 팀** (블루 평균 1500, 레드 평균 1300, 모두 K 32, 패배 배율 0.5)

- 블루 기대 승률 약 76%

| 결과 | 블루 | 레드 |
| --- | --- | --- |
| 블루 승리(예상대로) | +8 | −4 |
| 레드 승리(이변) | −12 | +24 |

같은 판에서 K 40인 신규 멤버가 레드에 있다면 이변 때 +30, 블루가 이기면 −5입니다.

### 4-4. 개인 순위 게임(롤체 등 팀이 없는 게임)

- 참가자 모든 쌍을 1:1 대결로 봅니다. 순위가 높은 쪽이 승리입니다.
- 모든 상대와의 `(결과 − 기대 승률)`을 더하고 `K ÷ (인원 − 1)`을 곱합니다. 이 값이 음수이면 패배 배율을 곱하고, 그다음 반올림합니다.
- 승패 기록은 **상위 절반**(2 × 순위 ≤ 인원)이 승리, 나머지가 패배입니다. 배율은 승패 기록이 아니라 점수 변동의 부호로 정합니다. 승리로 기록돼도 변동이 음수면 배율을 받습니다.
- 동순위는 없습니다. 순위는 1부터 빠짐없이 매깁니다.

### 4-5. 패배 배율의 효과

- **점수가 전체적으로 오릅니다.** 비슷한 5:5 경기(K 32)에서 이긴 팀 +16, 진 팀 −8이면 한 판에 전체 점수가 40점 늘어납니다.
- **참여량도 점수에 들어갑니다.** 승률 50%인 멤버도 경기당 평균 약 +4점이 쌓입니다. 랭킹은 실력과 함께 경기 수도 반영합니다.
- **늦게 온 멤버는 상대적으로 낮게 시작합니다.** 티어 시드는 고정이지만 기존 멤버 점수는 시즌 중에 오릅니다.
- 이미 승인된 경기는 다시 계산하지 않습니다. 배율 변경은 이후 승인부터 적용됩니다.

### 4-6. 반영되지 않는 경우

| 경우 | 점수 |
| --- | --- |
| `rated=false`로 만든 내전 | 결과 입력·승인은 같지만 점수는 그대로 |
| 노쇼로 표시된 참가자 | 대상에서 제외 |
| 팀에 배정되지 않은 참가자 | 대상에서 제외 |
| 한 팀이 0명이거나, 개인 순위 게임에서 대상이 2명 미만 | 점수 반영 없음 |
| 결과가 반려됨 | 제출자가 다시 입력(점수는 그대로) |
| 승인 **뒤**의 노쇼 표시·정정 | 이미 반영된 점수는 바뀌지 않음 |

점수에는 하한과 상한이 없습니다. 승인된 결과는 현재 수정하거나 취소할 수 없습니다.

## 5. 시즌과 점수

- 시즌은 보통 **3개월**(KST 달력 월 기준)이고, 시즌이 하나도 없을 때 첫 결과 승인 시 자동으로 만듭니다(`SEASON_AUTO_LENGTH_MONTHS`).
- 시즌이 끝나면(종료 시각 + 60초 이후) 종료 작업이 돕니다.
  - 그 시즌 **5경기 이상**인 멤버의 최종 순위를 저장합니다.
  - 게임별 1~3위에게 뱃지를 줍니다.
- 종료 작업은 점수를 바꾸지 않습니다. 새 시즌의 첫 결과가 승인될 때 각자의 새 점수 행이 소프트 리셋 값으로 만들어집니다.
- 시즌이 끝난 뒤 다음 승인이 나기 전까지는 「현재 시즌 없음」 상태입니다(Q2).
- 시즌 마지막 날 경기가 종료 후에 승인되면 새 시즌에 반영됩니다(Q3).

## 6. 팀 자동 밸런스와의 관계

ELO는 **결과 기록용 점수**이고, 팀을 나눌 때는 별도의 **실력값**을 씁니다.

```
실력값 = 반올림( w × 내전 점수 + (1 − w) × 티어 시드 )
w = min( 그 게임 승인 경기 수 / 10 , 1 )
```

- 신규 멤버는 티어 시드 비중이 크고, 10경기를 치르면 내전 점수만 씁니다.
- 현재 시즌 점수 행이 없으면 내전 점수 자리에 소프트 리셋 값(이전 행이 있을 때) 또는 티어 시드를 넣습니다.
- 팀 나누기는 정원이 2~16명 범위의 모든 조합을 따져 총 비용이 낮은 상위 3안을 보여 줍니다.
- 총 비용 = 전력 차 + 50 × 포지션 비용(1지망 0, 2지망 1, 그 외 3). 전력 차 = 두 팀 실력값 평균의 차이 × 전체 인원 ÷ 2.

따라서 ELO 시작값을 바꾸더라도 밸런스는 신규 멤버에게 티어 시드를 계속 반영합니다.

## 7. 랭킹에 나오는 방식

### 7-1. 내전 ELO 랭킹

- 게임별·시즌별 목록입니다. **그 시즌에 5경기 이상**(승 + 패) 치른 멤버만 나옵니다(`RANKING_ELO_MIN_GAMES`).
- 정렬 순서: 점수 높은 순 → 승률 높은 순 → 경기 수 많은 순 → 사용자 id.
- 5분 단위로 캐시합니다. 순위 변동(▲▼)은 이번 주 월요일(KST) 0시 기준 순위와 비교합니다.
- 끝난 시즌은 종료 때 저장한 최종 순위를 보여 줍니다.

### 7-2. 티어 랭킹(ELO와 별개)

```
티어 점수 = 티어 순서 × 400 + 디비전 점수 × 100 + LP
```

예: 다이아몬드 II 45LP = 6 × 400 + 2 × 100 + 45 = 2645. 마스터 이상은 디비전 없이 `티어 × 400 + LP`이고, 언랭은 제외됩니다. 이 점수는 내전 ELO와 섞이지 않습니다.

## 9. 열린 결정

### 9-1. 시작 점수를 전원 1000으로 통일할까요?

현재는 티어 시드(3-3)를 쓰는데, 이 때문에 신규 다이아 멤버(1800)가 지난 시즌을 뛴 같은 티어 멤버(예: 1400)보다 높게 시작할 수 있습니다(Q1).

| | 티어 시드(현재, 개발 문서 7-1) | 전원 1000 |
| --- | --- | --- |
| 장점 | 강한 신규 멤버의 초반 점수가 실력에 가까움 | 규칙이 단순하고 시작 역전이 없음 |
| 단점 | 지난 시즌 기록자와 역전이 생길 수 있음 | 강한 신규 멤버는 제자리를 찾기까지 시간이 걸리고, 상대 팀 점수 계산이 초반에 부정확 |
| 밸런스 | 영향 없음 | 실력값에 티어 시드가 계속 들어가서 영향 작음 |
| 변경 범위 | 없음 | 시드 계산 경로, 이월 판정, 테스트, 개발 문서 7-1 수정 |

## 10. 이 문서의 한계

- 위 수치는 코드와 단위 테스트로 확인했습니다. 실제 PostgreSQL에서 승인과 시즌 전환을 실행한 결과는 아직 없습니다.
- 3-4, 4-1, 4-3의 예시값과 6절 실력값 예(내전 점수 1100, 5경기, 티어 시드 1800 → 1450)는 빌드된 core 함수로 직접 계산해 일치를 확인했습니다. 실제 서버 화면에서 확인한 값은 아닙니다.
