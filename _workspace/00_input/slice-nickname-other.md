# 후속: 본인 닉네임 수정, 내전/모집 「기타」 게임

사용자 요청(2026-11-02). 문서에 없는 결정이라 아래를 기본값으로 잠근다. 구현 전에 사용자에게 다시 묻지 않는다.

## 포함

1. 본인 프로필에서 커뮤니티 닉네임을 수정한다.
2. 내전/모집 작성에 롤·롤체·스팀 옆 「기타」를 추가한다. 스팀에 없는 게임(마인크래프트, 오버워치 등)을 같이할 사람을 모집한다. 팀 밸런스는 없다.

## 닉네임 — 잠근 결정

- 대상은 커뮤니티 닉네임(`users.nickname`)이다. 라이엇 게임 이름·디스코드 사용자명은 바꾸지 않는다.
- API는 이미 `PATCH /me`가 확인 이후에도 닉네임을 바꾼다. 새 엔드포인트는 만들지 않는다.
- 규칙은 기존과 같다. 정규화(앞뒤·연속 공백), 2–50자, 한글·영문·숫자·밑줄·공백, 중복이면 `NICKNAME_TAKEN`.
- 횟수 제한·쿨다운은 없다.
- 화면은 본인 프로필 배너(`is_self`)에서만 고친다. 다른 멤버 프로필은 읽기 전용.
- 저장 후 본인 정보와 그 프로필을 다시 읽는다.

## 기타 게임 — 잠근 결정

- `games.code = other`, 표시 이름 `기타`. `GameCode`에 `other`를 넣는다.
- 속성: `has_positions false`, `has_teams false`, `has_results false`, `requires_steam_app false`, `start_requires_full false`.
- 정원은 스팀 모집과 같다. 2–16, 간격 1, 기본 8. 2명 이상이면 시작할 수 있다.
- 계정 연동 대상이 아니다. `GAME_PROVIDER_BY_CODE`·`GAME_CODES_BY_PROVIDER`에 넣지 않는다. 라이엇·스팀 연동, 티어·ELO·플레이타임 랭킹, 뱃지, 봇 티어 조회는 `other`를 받지 않는다.
- 모집글에 게임 이름 한 줄이 필수다. 필드명 `custom_game_name`. 앞뒤 공백 제거, 1–40자. 예: 마인크래프트, 오버워치. 플레이스홀더에 그 두 이름을 쓴다.
- `other`가 아니면 이 필드는 없거나 null. `other`인데 비어 있으면 `VALIDATION_FAILED`.
- 모집 중 수정에서 게임 코드는 그대로 두고 게임 이름만 바꿀 수 있다.
- 포지션·롤체 모드·스팀 앱·자동 밸런스·ELO(`rated`)는 저장하지 않는다. `appliedAutoBalance`는 false, `appliedRated`는 false.
- 목록 필터, 카드, 상세, 공유 문구, 캘린더 게임 필터에는 「기타」와 입력한 게임 이름이 나온다.
- 결과 입력·팀 나누기·레이팅 그래프에는 나오지 않는다(스팀 모집과 같은 취급).

## 제외

- 기타 게임의 승패, 순위, ELO, 팀 밸런스, 포지션.
- 기타를 위한 외부 API 연동.
- 닉네임 변경 이력, 운영진 강제 개명, 변경 횟수 제한.
- 관리자가 다른 멤버 닉네임을 바꾸는 기능.

## 선행

S0–S6 구현이 트리에 있다. `PATCH /me`와 스팀 모집(`has_teams`·`has_results` false) 패턴을 재사용한다.
