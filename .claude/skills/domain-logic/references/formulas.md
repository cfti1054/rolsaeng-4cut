# 계산 명세 (개발 문서 7장 기준)

문서 원문을 옮기고, 문서가 정하지 않은 부분은 **[해석]**으로 표시한다. [해석] 항목은 구현 보고서에 그대로 적어 사용자가 검토할 수 있게 한다.

## 1. ELO (7-1)

- 팀 레이팅 `R_team` = 팀원 레이팅 평균
- 기대 승률 `E_A = 1 / (1 + 10^((R_B − R_A)/400))`
- 갱신 `R'_i = R_i + K_i · (S − E)` — S: 승 1, 패 0. E는 **자기 팀 기준** 기대 승률(팀 평균으로 계산), K는 개인별.
- K: 기본 32, 해당 게임·시즌 내전 10경기 미만이면 40
- 첫 레이팅 시드: 티어당 200점 간격, 실버 1000 / 골드 1200 / 플래티넘 1400. 티어 연동 없으면 1000.
  - **[해석]** 나머지 티어는 같은 간격으로 연장: 아이언 600, 브론즈 800, 실버 1000, 골드 1200, 플래티넘 1400, 에메랄드 1600, 다이아 1800, 마스터 이상 2000. 디비전은 시드에 반영하지 않는다.
- **[해석]** 결과값은 정수로 반올림해 저장한다(`rating_history`에 before/after 정수).
- 롤체(팀 없음): 문서는 "개인 순위로 레이팅 갱신"만 정함. **[해석]** 8인 로비를 모든 쌍의 1:1 대결로 보고, 각 쌍에 대해 `K/(N−1)`로 갱신한 합을 적용한다(순위가 높으면 S=1).

## 2. 팀 밸런스 (7-2)

1. 실력값 `skill = w·elo + (1−w)·tierSeed`, `w = min(1, 내전경기수/10)`
2. 10명을 5:5로 나누는 126가지(대칭 제거: 1번 참가자를 항상 A팀에 고정하면 C(9,4)=126) 각각에 대해 `|ΣA − ΣB|`
3. 포지션이 있는 게임이면 팀마다 5! = 120 배정을 시도해 최소 포지션 비용을 구함: 1지망 0, 2지망 +1, 그 외 +3
4. 총 비용 = 실력 차 + 포지션 비용 × `POSITION_WEIGHT`
   - **[해석]** 문서는 두 비용의 합산 방식을 정하지 않았다. 기본 `POSITION_WEIGHT = 50`(포지션 1단계 불만 ≈ 실력 50점 차)으로 두고 config로 조정한다.
5. 비용 오름차순 상위 3안 반환. 각 안: 팀 구성, 팀별 포지션 배정, 실력 합, 실력 차, 포지션 비용.

계산량: 126 × 120 × 2 ≈ 3만 회 — 전수 탐색으로 충분.

## 3. 티어 점수 (7-3)

`tierScore = tierIndex × 400 + divisionScore × 100 + LP`
- **[해석]** `tierIndex`: 아이언 0 … 챌린저 9. `divisionScore`: IV=0, III=1, II=2, I=3 (높은 디비전이 높은 점수). 마스터 이상은 디비전이 없으므로 0.
- 롤체도 같은 식(롤체는 에메랄드 존재, 동일 체계).

## 4. 활동 집계 기간 (7-3)

- 한국 시간(UTC+9, 서머타임 없음) 기준. 주는 월요일 00:00 시작, 월은 1일 00:00 시작.
- `activityPeriod(kind: 'week'|'month', now) → { start, end }` (UTC Date, end는 배타적)
- 활동 랭킹 값 = 기간 내 `duration_sec` 합. **[해석]** 기간 경계에 걸친 활동은 `started_at`이 속한 기간에 전부 귀속한다.

## 5. 시즌 소프트 리셋 (7-3)

`newElo = 1000 + (oldElo − 1000) × 0.5` (비율은 config), 정수 반올림. 승·패는 새 시즌에서 0부터.

## 6. 노쇼 패널티 (7-4)

`isScrimBanned(noShowDates, now)`: `now` 기준 최근 30일 안의 노쇼가 3회 이상이면, **3번째 노쇼 시각부터 7일간** 참가 제한.
- **[해석]** 제한 시작 기준을 "3번째 노쇼가 기록된 시각"으로 본다. 반환값 `{ banned: boolean, until?: Date }`.

## 7. ELO 랭킹 노출 조건

해당 게임·시즌 내전 5경기 이상. 정렬: elo 내림차순, 같으면 승률 내림차순, 같으면 경기 수 내림차순 **[해석]**.
